# Support

Fazon is an open-source project with one maintainer. There is no guaranteed support.

- **Questions and problems:** open an [issue](https://github.com/gergodrazsdik/fazon/issues/new/choose). Check the [brief](docs/design/brief.md), the [tracker](docs/plan/TRACKER.md) and existing issues first.
- **Security problems:** never in a public issue. See [SECURITY.md](SECURITY.md).
- **Contributions:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Leave API keys and other secrets out of issues and logs you paste.
